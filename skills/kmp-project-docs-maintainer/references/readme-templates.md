# Consumer README Templates (Root, Docs, and Module)

This reference outlines the 3-Tier README standard for consumer Kotlin Multiplatform projects.

---

## 1. Root `README.md` (Project Front Door)

Place at the **root of the repository**:

```markdown
# [Project Name]

> One-line tagline explaining what this project does and who it is for.

## Quickstart

Run the project locally in 3 commands:

```bash
# 1. Clone the repository
git clone https://github.com/org/repo.git && cd repo

# 2. Run desktop development target
./gradlew :desktopApp:run

# 3. Run full verification suite
./gradlew check
```

## Architecture & Subsystems

This project follows the **6-Layer Clean KMP Architecture**:

- **`:core:*`** — Low-level primitives, math, rendering backends, and networking.
- **`:feature:<name>:*`** — Feature modules (`:model`, `:api`, `:domain`, `:data`, `:presenter`, `:ui`).
- **`:app`** — Target application entry points (Android, Desktop, iOS, Wasm).

## 3. Per-Module `README.md` (Code-Colocated)

Place inside individual modules that export public APIs or require non-obvious setup (e.g. `:core:math/README.md`):

```markdown
# :core:math

High-performance linear algebra and spatial math primitives.

## Supported Platforms
- `commonMain` (Pure Kotlin multiplatform)
- `desktopMain` (JVM SIMD vector extensions)

## Public API Exports
- **`Mat4`**: 4x4 transform matrix (perspective, lookAt, decompose, inverse).
- **`Vec3f` / `Vec2f`**: 3D and 2D vector operations.
- **`Quat`**: Quaternion rotation with spherical linear interpolation (`slerp`).
- **`AABB`**: Axis-aligned bounding box intersection and containment.

## Direct Dependencies
- *None (Zero third-party dependencies).*

## Quick Usage
```kotlin
val modelMatrix = Mat4.identity()
    .translate(position)
    .rotate(rotationQuat)
    .scale(scale)
```
```
