# KMP Agent Skills

This is a searchable guide to the repository's Kotlin Multiplatform skills. Each skill
page is rendered from its source `SKILL.md`; the generated site does not maintain a second
copy of the guidance.

## Start here

- [Browse the skill catalog](skills/index.md)
- [Understand how skills are selected](routing.md)
- [Review the latest skill quality scan](quality.md)

Skill pages explain what a skill covers, when it should activate, its workflow and safety
boundaries, and links to any detailed references. Use search to find a topic, API, or
trigger phrase across the collection.
